Connect your Google Calendar

This takes about 10 minutes and you only do it once. You'll create a permission key (called a Client ID) that lets the planner read and write your Google Calendar. Nothing is shared with anyone else.

This page is open as a plain file. Google sign-in and the saved key only work when the folder is served through a local server. Stop here and follow the instructions in the box below, then reload this page from the address it gives you.

Before you start

Keep all three files in the same folder: this setup page, the planner page, and the client_id.txt file you'll create in step 5.

Start a small local server in that folder. Open the Terminal (Mac) or Command Prompt (Windows), move into the folder, and run:

python3 -m http.server 8000

On Windows, if python3 doesn't work, try python -m http.server 8000. Leave this window open while you use the planner.

Then open this page at http://localhost:8000/index.html.

Setup steps

Step 1

Create a project in Google Cloud.

  1. Go to console.cloud.google.com and sign in with the Google account whose calendar you want to use.
  2. At the top, click the project name, then New project.
  3. Name it something like Weekly Planner and click Create. Make sure it is selected before continuing.
Step 2

Turn on the Google Calendar API.

  1. In the search bar at the top, type Google Calendar API and open it.
  2. Click Enable.
Step 3

Set up the consent screen. This is the screen Google shows when you sign in.

  1. Go to Google Auth Platform (or APIs & Services → OAuth consent screen) and click Get started.
  2. App name: Weekly Planner. User support email: your own email address.
  3. Audience: choose External, then continue.
  4. Contact information: your email address. Accept the policy and click Create.
  5. Open Audience in the left menu, scroll to Test users, click Add users, enter your Google email, and save.

Keeping the app in "Testing" is fine for personal use. Google may show a warning that the app isn't verified. Click Advanced, then continue, to proceed.

Step 4

Create the Client ID.

  1. Go to Clients (or Credentials) and click Create client.
  2. Application type: Web application. Name: Planner.
  3. Under Authorized JavaScript origins, click Add URI and paste this address exactly:
    http://localhost:8000
  4. Leave the redirect URI section empty. Click Create.
  5. A window shows your Client ID. It ends in .apps.googleusercontent.com. Copy it.
Step 5

Save your Client ID.

  1. Paste the Client ID into the box below.
  1. Your browser downloads a file called client_id.txt.
  2. Move that file into the same folder as this page and the planner. If your browser saved it to Downloads, drag it across.
  3. If a file with that name already exists, replace it.
Step 6

Open the planner.

  1. Click the button below, then click Connect Google Calendar and approve access with your Google account.

If something goes wrong

  • "Access blocked" or "redirect_uri / origin mismatch": the address in Step 4 doesn't match the address in your browser. Check it's exactly http://localhost:8000 with no trailing slash, then wait a few minutes and try again.
  • "Client_id.txt was not found": the file isn't in the same folder as the planner, or it has a different name. Check it's called client_id.txt, not client_id.txt.txt.
  • "Access not granted" or "app is in testing": add your email under Test users in Step 3.
